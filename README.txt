VELORA VILLAS — PREMIUM SINGLE-PAGE WEBSITE

Open index.html in a modern browser. No npm or build step is required.

Folder structure:
- index.html: page structure
- css/styles.css: responsive styling and typography
- js/main.js: menu, reveal effects, auto carousel, drag/arrows, reviews, FAQ and video control
- assets/images/: local image assets cropped from the visual references supplied in this conversation
- assets/video/: reserved for a locally hosted hero video if you add one

Carousel behavior: it moves continuously, pauses while hovered or keyboard-focused, supports drag and arrow controls, and respects reduced-motion settings.

The video source is streamed from Pexels; if offline, the local hero poster still displays. The WhatsApp number and example villa details/testimonials are placeholders; replace before publishing.
